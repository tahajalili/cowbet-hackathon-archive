# CowBet Hackathon Archive

Records of **CowBet**, our winning project at the **DeFi The Conventional** hackathon.

**Result:** Winner, Gaming Theme 1st Place

## The project

CowBet is an on-chain betting platform built on Terra. Bets are locked in and immutable, and stakers farm Anchor rewards for the time their money is staked, so every participant earns a return regardless of the bet's outcome.

- **Smart contract (Rust):** adapted from the InterWasm DAO-voting template. It receives bets during a 2-3 day deposit period, locks them when the period ends, and lets users claim winnings plus Anchor rewards.
- **Web front end (React):** designed by Taha Jalili. The front-end code was lost when the original team repo was deleted.
